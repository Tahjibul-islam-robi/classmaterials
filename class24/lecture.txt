Class 24: Testing whether a character is a vowel
================================================

Instructor explanation
Explain character comparisons and the vowel set a, e, i, o, u. The current example accepts letters; discuss how to distinguish a consonant from punctuation or a digit.

Board walkthrough
1. Ask learners what problem the example is solving.
2. Point out the relevant C++ syntax and name the values that change as the program runs.
3. Trace one ordinary input, then test a boundary case. Have learners predict the output before running the program.
4. Summarize the rule in learners' own words and connect it to the next class.

Guided practice
Extend the program to report non-letter input separately, then test upper- and lowercase vowels.

Independent task
Make one small variation to the example in this folder. Write down the expected output first, run the program, and explain any difference. Include one edge case appropriate to the topic.

Check for understanding
- Which concept from this lesson controls the program's behavior?
- What changes when the input or state changes?
- What boundary case should the program handle?
